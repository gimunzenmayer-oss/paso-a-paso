# Correos: guía para Giselle

## Lo comprobado
El código de seis dígitos permite entrar; la prueba aislada de Resend llegó a Recibidos. Los ocho avisos simulados de Hotmart respondieron 200 tras reparar los registros simultáneos. Esto no equivale a una compra real ni acredita el envío automático postcompra.

## Si alguien pagó y no puede entrar
1. Comprobar en Hotmart el estado del pago y el correo usado, sin pedir datos de tarjeta.
2. Abrir https://paso-a-paso-sigma.vercel.app/entrar y solicitar un código nuevo con ese correo. El código vence a los diez minutos.
3. Revisar Resend → Emails para saber si el mensaje fue aceptado, entregado o rebotado. Entregado no demuestra Recibidos.
4. Si sigue sin acceso, revisar la conexión de compra y el estado del cliente; nunca marcarlo pagado solo por recibir un correo de soporte.
Nunca pedir contraseñas, códigos de acceso o claves por chat.

## Antes de compartir el enlace de venta
Comprobar compra/inicio real de prueba, fecha e importe del primer cobro, aviso previo, correo de acceso, entrada, cancelación y reembolso. La prueba exige intervención de la dueña para cualquier contratación. No se efectuó ninguna compra automática.
